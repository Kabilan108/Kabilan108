\section{Research and engineering experience}
\role{Machine Learning Engineer}{Aug 2024 -- Present}{Moberg Analytics, Philadelphia, PA}
\begin{itemize}
\item Led model development, experiments, cross-validation, testing, manuscript drafting, and peer-review revisions for a first-author PRECICECAP study on arterial blood pressure artifact detection, published in \textit{Biomedical Signal Processing and Control}. Released ABP and related ECG artifact-detection models and inference code through OkekeClean.
\item Implemented density spectral array (DSA) processing for ELECTRO-BOOST, an ancillary study to BOOST-3. Processed over 1,200 EEG recordings from over 200 patients; 10 clinicians use the DSA alongside raw EEG in the study's change-point review workflow.
\item Built offline and on-demand DSA pipelines that preserve causal filter behavior when processing arbitrary recording segments. The feature is available at at least three hospitals in the US and Europe, in addition to the study environment.
\item Developed a custom EDF parser after benchmarking existing libraries against memory and loading-time requirements. It supports access to over 1,100 EEG files in ELECTRO-BOOST's shared review platform.
\item Developed Moberg's ACME mobile application and sensor integrations for the US Army TATRC AutoDoc program, funded through MTEC. Rebuilt a React Native prototype in native Kotlin to support concurrent Bluetooth sensor streams and device SDKs. Assembled five kits; delivered four for TATRC evaluation and retained one internally.
\item Own EEG paging and data-loading improvements for continuous playback in a cloud environment. Support customer deployments, diagnose failures, and deliver hotfixes; contribute requirements and QMS documentation toward a planned 510(k) submission.
\item Built an early CLARA AI prototype for Moberg's successful Ben Franklin Technology Partners funding pitch and participated in technical Q\&A. Currently developing a research-agent demonstration for an upcoming NCS informatics workshop.
\end{itemize}
